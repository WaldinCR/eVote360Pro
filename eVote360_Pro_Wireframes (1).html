Pantalla 21 — Acceso Denegado (403)

Se muestra cuando un usuario intenta acceder directamente por URL a una ruta para la que no tiene permiso según su rol. Protege contra acceso no autorizado. Cada mensaje es específico al contexto del intento.

evote360.gob.do/admin/ciudadanos

Acceso denegado

No tiene permiso para acceder a esta sección.

Escenarios de acceso denegado

403

Elector intenta acceder al panel admin

Ruta: /admin/* sin autenticación → Redirige a /acceder

403

Dirigente intenta acceder a módulos admin

Ruta: /admin/ciudadanos → Acceso denegado, redirige a home del dirigente

403

Elector intenta saltarse el proceso OCR por URL

Ruta: /boleta/* sin completar pasos previos → Redirige al paso correspondiente

403

Ciudadano que ya votó intenta votar de nuevo

Ruta: /votar → Muestra mensaje "Ya ejerció su voto" y bloquea el proceso

Acceso controlado por rol · Protección contra acceso no autorizado por URL
